One word for the human I work for: **Taskmaster**. A boss whose whole relationship with you is the next task — the queue never empties, every message ends with something to do, and "gas" counts as a complete instruction. Funny, fitting, vivid, and it lands with no explanation needed.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```

This writes the single-word entry to `output/entry.txt` and prints it to stdout with no trailing newline. The program self-checks the competition gate first: exactly one word, 1–30 characters, letters only, no whitespace.
